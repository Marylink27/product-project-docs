# Проектный пакет: запуск собственной торговой марки

Полный комплект документов руководителя проекта на примере вывода на полку первого SKU собственной марки розничной сети: замороженные ягоды в шоколаде через контрактного производителя.

| Документ | Что показывает |
|---|---|
| [01. Устав](01-charter.md) | обоснование, SMART-цели, объём, результаты с критериями приёмки, вехи, команда |
| [02. WBS и план-график](02-wbs-schedule.md) | 26 пакетов работ с зависимостями, диаграмма Ганта, критический путь, резерв |
| [03. RACI](03-raci.md) | кто исполняет, отвечает, консультирует по 16 работам |
| [04. Реестр рисков](04-risks.md) | 9 рисков с оценкой, ответом, владельцем и триггером, карта рисков |
| [05. Бюджет и экономика](05-budget.md) | бюджет с резервом, себестоимость, взвешенный выбор производителя, точка безубыточности |
| [06. Статус-отчёт](06-status-report.md) | еженедельный отчёт спонсору: RAG, вехи, проблема и решение, изменения рисков |

Что здесь важно для проекта такого типа: регуляторные шаги (декларация ЕАЭС, маркировка по ТР ТС 022/2011) стоят на критическом пути, а холодовая цепь и место в морозильниках магазинов решают, увидит ли покупатель товар вообще.

Названия, цены и даты изменены, логика решений сохранена.
